# SIM_DRIFT — 가격 모델 드리프트 점검 (보고 전용)

> 생성: `dotnet run --project tools/dotnet-harness -- sim drift`. 손으로 고치지 말 것. 틱 로그수익률 r = t(3) × 0.010, |r| ≤ 0.25. 마팅게일이면 E[P(t+1)/P(t)] = E[e^r] = 1.

## 1. 틱당 E[P(t+1)/P(t)] (슬롯 = 1틱, 1,000만 샘플, 고정 시드)

| 항목 | 값 |
|---|---|
| 표본 평균 E[e^r] | 1.0001353 |
| 표준오차 | 0.0000053 |
| 95% 신뢰구간 | [1.0001249, 1.0001457] |
| 1과의 차이 | 0.0001353 (z = 25.4) |
| 평균 r | -0.0000057 |
| 상한(|r| = 0.25)에 걸린 비율 | 0.01457% |
| 이론 근사 1 + Var(r)/2 (Var t3 = 3) | 1.0001500 |

→ 로그 드리프트 c = ln E[e^r] = **0.0001353** (틱당). 30일 = 150틱이면 가격 기대치가 약 2.05% 오른다.

**보정 후** (`Rules.CoinDriftC` = 0.0001353 를 뺀 틱): E[e^(r−c)] = 1.0000000 (±0.0000053, 1과의 차이 z = -0.0).

## 2. 서브틱 포함 경로 (100만 슬롯 × 12 서브틱, 가격 1억 고정 출발)

- 슬롯 종가 비율 E[close/open] = 1.0000131 (±0.0000168) — 서브틱 경로의 합이 슬롯 r이므로 1번 표와 같다.
- 서브틱당 평균 비율(경로 내부 12걸음) = 1.0000018 — 브라운 다리형 보정 때문에 걸음 단위 기댓값은 슬롯 단위와 다를 수 있다(참고).
