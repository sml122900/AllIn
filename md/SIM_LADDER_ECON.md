# SIM_LADDER_ECON — 사다리 경제 그리드 (보고 전용, 규칙 기본값 불변)

> 생성: `dotnet run --project tools/dotnet-harness -- sim ladder`. 손으로 고치지 말 것.
> 시드 1..1000, 무조건 승리 q = 홀덤 3.0% 포함, 리엔트리 허용(참가비 × (1 + 리엔트리) 가 총 비용). 차트 봇 = HUD 4 권고, 직감 봇 = 포켓페어·A 포함·브로드웨이 두 장.
> ROI = (도달률 × 시트 가치 − 평균 총 참가비) / 평균 총 참가비. 시트 가치 = 기존 방식: 펍 시트 = 새틀라이트 참가비 100,000원(현행값 고정), 새틀 시트 = **같은 봇의 메인 평균 세후 상금**(메인은 이번에 건드리지 않음).
> ★ = 목표 충족(차트 봇 ROI ∈ [−10%, 0%] 이고 직감 봇 ROI ≤ -20.0%). 판단은 사용자.

메인 평균 세후 상금(시트 가치): 차트 1,973,400원 / 직감 1,220,700원.
