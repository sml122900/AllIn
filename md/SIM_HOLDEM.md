## 실력 측정 (측정만 — 수용 기준 아님)

히어로 자리 1석 + 기본 로스터 8석, 리엔트리 없음, Kind별 1000회. 비교 기준선: 우승률 1/9 = 11.1%.

ROI = (획득 상금 가치 − 참가비) / 참가비. 상금 가치: Pub 1위 시트 = 새틀라이트 참가비 100,000원, 펍 포인트 = 0.
새틀라이트 1위 시트 = 메인 참가비가 정해져 있지 않아, **같은 플레이어의 메인 평균 세후 상금**으로 환산(아래 Main 행). Main은 시트로 입장해 참가비가 없으므로 ROI 대신 평균 세후 상금.
