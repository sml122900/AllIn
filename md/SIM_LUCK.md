# SIM_LUCK — "무조건 승리" 확률 q 밸런싱 (DESIGN.md E4)

> 생성: `dotnet run --project tools/dotnet-harness -- sim luck`. 손으로 고치지 말 것. 보고 전용 — **q 기본값은 0으로 유지**, 결정은 사용자.
