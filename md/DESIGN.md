### B5. 코인 선물 — 청산 체인 (v0.3)

> "청산가 1cm 앞에서 ㄹㅇ 기도메타할떄 기분 .. 청산후 분노의 100배 뱃 .. 나머지은행계좌 업비트에 입금했는데 24시간 룰떄문에 전송도못해서 안절부절할떄 그모습 .. 다음날입금했는데 청산됬는데 본절가 와있을떄 그 좌절 .."
>
> 네 장면(관전·분노·24시간 룰·본절)은 아래 규칙에서 자연 발생해야 한다. 특정 날 청산시키는 등 스크립트 강제 금지. 이 개편은 신규 기능이라 "수치 동결" 예외 — 기존 튜닝 후보(멘탈 스파이럴, 로또 −1)는 여전히 손대지 않는다.

**돈의 세 칸** — 은행 / 국내 거래소(원화·현물, 가칭) / 해외 선물 거래소 지갑(가칭). 실제 브랜드명 사용 금지, `Texts.cs`에 임시 이름.

| 항목 | 값 |
|---|---|
| 시작 자금 | 20,000,000 전액 은행 (Day 1 새벽, 오프닝 텍스트 후) |
| 월세·식비·알바 일당·로또 | 전부 은행에서 나가거나 은행으로 들어옴 |
| 선물 증거금 | 해외 지갑에서만 나온다 |
| 이동 | 슬롯 소비 없음 |
| 은행 → 국내 입금 | 즉시. 입금 시점부터 5슬롯(24시간) 동안 국내 → 해외 전송 잠김. 추가 입금 시 잠김은 **마지막 입금 기준으로 갱신**(연장 아님, 재설정) |
| 국내 → 해외 전송 | 잠김 해제 후 가능. 다음 슬롯 경계에 도착("전송 중" 표시) |
| 해외 → 국내, 국내 → 은행 | 각각 1슬롯 지연 |
| 이동 수수료 | 없음(임시) |
| 총자산 | 은행 + 국내 + 해외 + 전송 중 금액 + 포지션 평가 |
| room 판정 | 은행 + 국내 + 해외 + 전송 중 (포지션 제외) |

Day 1 새벽에 은행→국내→해외까지 옮겨야 Day 2 같은 슬롯부터 첫 거래가 가능하다 — 의도된 첫 경험.

**가격 · 서브틱 경로**

| 항목 | 값 |
|---|---|
| 가능 슬롯 | 전부 (열기·닫기 각각 슬롯 1개 소비, 밤이면 밤샘) |
| 시작가 | 100,000,000원 |
| 슬롯 틱 수익률 | 로그수익률 r = t(df=3) × 0.010, \|r\| ≤ 0.25 — **기존과 동일한 분포**(슬롯 종가 분포는 불변) |
| 서브틱 경로 | 슬롯의 r을 서브틱 12개로 분해: 증분 t(df=3) × (0.010/√12)를 **서브틱 전용 RNG 스트림**(시장 RNG와 분리)으로 12개 샘플한 뒤, 합이 r이 되도록 선형 보정(브라운 브리지 근사). 경로는 슬롯 시작 시 미리 생성(되돌리기 없음과 일관) |
| 청산 판정 | 경로 전체(꼬리 포함) 대상 — 포지션 보유 슬롯에서만 계산. 종가가 회복했어도 경로 중 청산가를 찍으면 청산. 종가만으로는 청산이 아니었을 경우 "꼬리 청산" 플래그 기록 |
| 가격 반올림 | 매 서브틱 원 단위 정수 |
| 레버리지 | 5 / 10 / 25 / 50 / 100 |
| 증거금 투입 | 해외 지갑 잔고의 0~100% (슬라이더) |
| 포지션 | 1개만 |
| 수수료 | 진입·종료 각각 명목 × 0.05% |
| 청산 | 미실현손실 ≥ (증거금 + 추가 증거금) × 0.9 → 소멸(회수 0) |
| 증거금 추가 | 해외 지갑 잔고에서 추가 투입 가능. 명목·수량은 불변, **청산가만 재계산**되어 남은 서브틱에 적용 |
| 예약 주문 | 없음 |

**정산식 (해석):**
- 투입액 C(해외 지갑에서 빠짐), 명목 N = C × 레버리지, 진입 수수료 = N × 0.0005 → **증거금 M = C − 진입 수수료**. 수량 q = N / 진입가(고정, 이후 변하지 않음).
- 미실현손익 = q × (현재가 − 진입가) × (롱 +1 / 숏 −1).
- 증거금 추가 A(해외 지갑에서 빠짐, 누적 가능, ΣA)는 M에 더해지되 N·q는 그대로 — 청산 기준 손실 = (M + ΣA) × 0.9.
- 청산가(롱) = 진입가 × (1 − 0.9(M+ΣA)/N), (숏) = 진입가 × (1 + 0.9(M+ΣA)/N). ΣA가 바뀔 때마다 재계산.
- 수동 종료(관전 중 손절 포함): 종료 수수료 = q × 현재가 × 0.0005, 돌려받는 돈 = max(0, M + ΣA + 미실현손익 − 종료 수수료) → **해외 지갑으로**.
- 실현손익(통계) = 돌려받은 돈 − (C + ΣA). 청산이면 −(C + ΣA).
- 100배면 왕복 수수료가 투입액의 10% — 의도.
- 청산 서브틱이 밤/새벽 슬롯으로 넘어가는 순간이면 E2, 그 외는 E1. 잠든 상태에서는 관전 없이 곧장 E2(꼬리 청산이라도 동일).

### C1. 규칙 (NLHE 표준)
- 9-max 싱글 테이블. 버튼·SB·BB. 헤즈업은 버튼 = SB(프리플랍 선 액션, 포스트플랍 후 액션).
- 액션: 폴드 / 체크 / 콜 / 벳 / 레이즈 / 올인. 최소 벳 = BB. 최소 레이즈 증가분 = 직전 레이즈(또는 벳) 크기.
- 풀 레이즈 미만 올인은 이미 액션한 플레이어의 레이즈 권한을 재개하지 않는다(콜/폴드만).
- 사이즈 입력: 프리셋(1/2팟·2/3팟·팟·올인) + 슬라이더.
- 사이드팟 정확히. 7장 중 최고 5장. 앤티 없음.
- 탈락 자리는 빈 자리. 2명 = 헤즈업 룰, 1명 = 종료.
- 쇼다운(올인 없음): 마지막 어그레서(리버에서 마지막으로 벳/레이즈한 사람)부터 공개, 없으면 버튼 왼쪽부터. 폴드로 끝나면 미공개.
- 올인 공개(2026-09-25 확정): 한 명 이상 올인이고 남은 베팅 액션이 없으면 그 즉시 참여자 전원의 카드를 버튼 왼쪽부터 오픈한 뒤 보드를 깐다. 리버에서 올인이 콜된 경우도 동시 공개. 이 경우 어그레서 순서 공개는 없다.
- 나머지 칩(나누어떨어지지 않는 칩)은 버튼 왼쪽에서 가까운 승자에게.
- 데드 버튼 대신 단순 규칙: 버튼은 매 핸드 다음 생존자에게 이동, SB·BB는 버튼 다음 생존자 순서.

### C4. 상대 AI
**프리플랍**
- 169 핸드 클래스 순위(1~169, 랜덤 1:1 대비 에퀴티 순) 내장.
- 유효스택(bb) = min(내 스택, 최대 상대 스택) / BB.
- 유효스택 ≤ 15bb → 푸시/폴드: 표(포지션 UTG·MP·CO·BTN·SB × 3·5·7·10·15bb → 푸시 상위 %, 오픈 푸시에 대한 콜 상위 %). 단조성: 후위일수록·짧을수록 넓게.
- 유효스택 > 15bb → 오픈 2.5bb, 림프 없음. 오픈 %: UTG 12 / MP 15 / CO 25 / BTN 42 / SB 36.
- 오픈 앞에서: 상위 5% 3벳(3×) / 다음 8% 콜 / 나머지 폴드. 3벳 받으면 상위 4% 올인·콜 / 나머지 폴드.
- 스택 ≤ 2 × 팟이면 공격 액션은 올인.
- 포지션 매핑(9-max, 버튼 기준): BTN, SB, BB, CO(버튼 오른쪽 1), MP(오른쪽 2~3), 나머지 UTG. BB는 방어(콜 레인지 = 콜 표/오픈 앞 규칙).

**포스트플랍**
- 에퀴티: 몬테카를로 400회(상대 핸드 랜덤·남은 보드 랜덤, 상대 수 = 남은 상대 수). 스트리트당 1회 계산, 캐시.
- eq = 에퀴티, po = 콜액 / (팟 + 콜액).
- 체크로 넘어옴: eq ≥ 0.62 → 벳 2/3팟 / eq ≥ 0.45 → 체크 / 그 외 체크(p_bluff 확률로 벳 1/2팟).
- 벳 받음: eq ≥ po + 0.20 → 레이즈 2.5× / eq ≥ po + margin → 콜 / 그 외 폴드.
- 스택 ≤ 2 × 팟이면 레이즈 대신 올인.

**성격 4종**
| 성격 | 레인지 배율 | p_bluff | margin | 기타 |
|---|---|---|---|---|
| Tight(직장인) | × 0.7 | 0.03 | +0.08 | |
| Station(취객) | × 1.2 | 0.05 | −0.12 | 레이즈 임계 +0.15 |
| Maniac(대학생) | × 1.6 | 0.30 | −0.05 | 벳 사이즈 × 1.2 |
| Pro(지망생) | × 1.0 | 기본 0.10 | 0.00 | 푸시/폴드 표 정확, 상대가 Station이면 밸류 벳 임계 −0.05 |

- 로스터(AI 8명): Pub = Tight 2·Station 3·Maniac 2·Pro 1 / Satellite = 2·2·2·2 / Main = Tight 2·Station 1·Maniac 1·Pro 4. 메인 충원 = Pro 60% / 나머지 각 13.3%.
- AI 한글 표시 이름(임시 랜덤). 성격은 화면에 안 보임.
- 레인지 배율은 오픈 %·푸시 %·콜 %·3벳 % 모두에 곱한다(100% 상한).

### D2. 월세 (연속 인생용 보완 — 임시 해석)

### D3. 파산 판정 · E9
| 항목 | 값 |
|---|---|
| 판정 시점 | 매 **새벽 슬롯 진입 시** (Day 1 시작 제외) |
| 조건 | 총자산(은행 + 국내 + 해외 + 전송 중 + 포지션 평가) **< 월세 + 식비 7일분 = 450,000 + 7 × 12,000 = 534,000** |

| [버틴다] | 아무 일 없음. 매 새벽 다시 판정(알바로 버티기 가능). **매일 E9 팝업은 없다** — HUD에 "파산 D+N / 14" 한 줄 카운트다운만. 선택 팝업은 **선언일과 7일째 새벽**에 한 번씩([원양어선을 탄다] / [계속 버틴다]). 총자산이 기준 이상으로 회복하면 파산 상태 해제 + 한 줄 알림(문구 임시) |
| 강제 승선 | 파산 상태가 시작된 날로부터 **14일째 새벽**에도 여전히 파산이면 선택지 없이 원양어선 강제(임시 규칙 — 신용불량 엔딩은 ② 이후). 14일째 새벽에 기준을 넘겼다면 해제가 우선한다. 알바만으로 자산 ≈ 0에서 534,000을 넘기는 데 (51,600 − 12,000) × 14 = 554,400 ≥ 534,000 → 14일째 새벽에야 간신히 도달(여유 20,400원, 하루도 쉴 수 없음) |
| 헤드리스 봇 | E9에 응답하지 않으면 [버틴다]와 같다. 강제 승선은 자동 출발(포지션은 "그대로 둔다") |

### D7. 시뮬 (B11 보완)
- A~E는 "30일 봇" 기준선이라 봇이 E9에 응답하지 않는다. 승선까지 자동으로 굴리면 30일 시뮬이 수백 일로 늘어나므로 **A~E는 파산 판정 끄기 옵션(`BankruptcyEnabled = false`)으로 기존 정의 그대로 유지**한다. 별도로 A는 규칙을 켠 채로도 결과 불변(파산 안 함)을 테스트로 확인.
- **F "인생 반복 파산"(보고 전용, 수용 기준 없음)**: 100배 올인 반복 봇(입금→해외 지갑→100배 올인 롱, 청산되면 반복, 알바 병행)이 파산 → 즉시 승선([정리]) → 복귀를 **5회** 겪을 때까지 진행. 보고: 승선 횟수별 나이 / body 최대치 / 지급액 / 질병 0회 비율, 5회 도달 나이 중앙값, 질병 횟수·병원비 합계.
