### B1. 시간
| 항목 | 값 |
|---|---|
| 하루 슬롯 | 5개, 순서 고정: 새벽(04~08) / 오전(08~12) / 오후(12~18) / 저녁(18~23) / 밤(23~04) |

**행동 종류 (해석 — 원문 "행동 1개 = 슬롯 1개 소비"를 아래처럼 구현):**
- **슬롯 행동**: 슬롯을 끝내고 시간을 넘긴다. 식당알바, 쉬기(낮)/잠(밤). (확장: 상하차·노가다·공부)
- **즉시 행동**: 슬롯 안에서 하고, 시간은 흐르지 않는다. 코인 진입·종료, 로또 구매.
- 근거: "같은 슬롯 열고 닫기 불가" 규칙, "잠든 슬롯에도 청산", 시뮬 D(밤 진입 → 새벽 종료)가 모두 "코인 진입이 슬롯을 끝내지 않는다"를 전제한다.
- 슬롯을 끝낼 때 슬롯 행동을 안 고르면: 낮 = 쉬기(body +5), 밤 = 잠(body +30, mental +3).
- 밤에 **슬롯 행동**을 하면 밤샘(회복 0, mental −5). 즉시 행동(밤에 코인 진입 등)은 잠을 깨지 않는다. 프로토타입에는 밤 슬롯 행동이 없다(확장: 상하차).

### B5. 코인 선물 (BTC/USDT 무기한, 단순화)
| 항목 | 값 |
|---|---|
| 가능 슬롯 | 전부 (즉시 행동) |
| 시작가 | 100,000,000원 |
| 틱 수익률 | 로그수익률 r = t(df=3) × 0.010, \|r\| ≤ 0.25. 가격은 매 틱 원 단위 정수로 반올림(세이브가 정확히 복원되도록) |
| 레버리지 | 5 / 10 / 25 / 50 / 100 |
| 증거금 투입 | cash의 0~100% (슬라이더) |
| 포지션 | 1개만 |
| 수수료 | 진입·종료 각각 명목 × 0.05% |
| 청산 | 미실현손실 ≥ 증거금 × 0.9 → 증거금 전액 소멸(회수 0) |
| 수동 종료 | 진입 슬롯과 다른 슬롯에서만(최소 1틱) |
| 예약 주문 | 없음 |

**정산식 (해석):**
- 투입액 C(현금에서 빠짐), 명목 N = C × 레버리지, 진입 수수료 = N × 0.0005 → **증거금 M = C − 진입 수수료**.
- 수량 q = N / 진입가. 미실현손익 = q × (현재가 − 진입가) × (롱 +1 / 숏 −1).
- 청산 판정은 매 틱 가격이 움직인 직후(알바 중·잠든 슬롯 포함). 청산가(롱) = 진입가 × (1 − 0.9M/N), (숏) = 진입가 × (1 + 0.9M/N).
- 수동 종료: 종료 수수료 = q × 현재가 × 0.0005, 돌려받는 돈 = max(0, M + 미실현손익 − 종료 수수료).
- 실현손익(통계) = 돌려받은 돈 − C (수수료 포함). 청산이면 −C.
- 100배면 왕복 수수료가 투입액의 10% — 의도.
- 청산 틱이 밤/새벽 슬롯으로 넘어가는 틱이면 E2, 그 외(오전·오후·저녁으로 넘어가는 틱)는 E1.

## Part C — 홀덤 미니게임

### C1. 규칙 (NLHE 표준)
- 9-max 싱글 테이블. 버튼·SB·BB. 헤즈업은 버튼 = SB(프리플랍 선 액션, 포스트플랍 후 액션).
- 액션: 폴드 / 체크 / 콜 / 벳 / 레이즈 / 올인. 최소 벳 = BB. 최소 레이즈 증가분 = 직전 레이즈(또는 벳) 크기.
- 풀 레이즈 미만 올인은 이미 액션한 플레이어의 레이즈 권한을 재개하지 않는다(콜/폴드만).
- 사이즈 입력: 프리셋(1/2팟·2/3팟·팟·올인) + 슬라이더.
- 사이드팟 정확히. 7장 중 최고 5장. 앤티 없음.
- 탈락 자리는 빈 자리. 2명 = 헤즈업 룰, 1명 = 종료.
- 쇼다운: 마지막 어그레서(마지막 스트리트에서 마지막으로 벳/레이즈한 사람)부터 공개, 없으면 버튼 왼쪽부터. 폴드로 끝나면 미공개.
- 나머지 칩(나누어떨어지지 않는 칩)은 버튼 왼쪽에서 가까운 승자에게.
- 데드 버튼 대신 단순 규칙: 버튼은 매 핸드 다음 생존자에게 이동, SB·BB는 버튼 다음 생존자 순서.

### C4. 상대 AI
**프리플랍**
- 169 핸드 클래스 순위(1~169, 랜덤 1:1 대비 에퀴티 순) 내장.

- 유효스택 ≤ 15bb → 푸시/폴드: 표(포지션 UTG·MP·CO·BTN·SB × 3·5·7·10·15bb → 푸시 상위 %, 오픈 푸시에 대한 콜 상위 %). 단조성: 후위일수록·짧을수록 넓게.
- 유효스택 > 15bb → 오픈 2.5bb, 림프 없음. 오픈 %: UTG 12 / MP 15 / CO 25 / BTN 42 / SB 36.
- 오픈 앞에서: 상위 5% 3벳(3×) / 다음 8% 콜 / 나머지 폴드. 3벳 받으면 상위 4% 올인·콜 / 나머지 폴드.
- 스택 ≤ 2 × 팟이면 공격 액션은 올인.
- 포지션 매핑(9-max, 버튼 기준): BTN, SB, BB, CO(버튼 오른쪽 1), MP(오른쪽 2~3), 나머지 UTG. BB는 방어(콜 레인지 = 콜 표/오픈 앞 규칙).

**포스트플랍**
- 에퀴티: 몬테카를로 400회(상대 핸드 랜덤·남은 보드 랜덤, 상대 수 = 남은 상대 수). 스트리트당 1회 계산, 캐시.
- eq = 에퀴티, po = 콜액 / (팟 + 콜액).
- 체크로 넘어옴: eq ≥ 0.62 → 벳 2/3팟 / eq ≥ 0.45 → 체크 / 그 외 체크(p_bluff 확률로 벳 1/2팟).
- 벳 받음: eq ≥ po + 0.20 → 레이즈 2.5× / eq ≥ po + margin → 콜 / 그 외 폴드.
- 스택 ≤ 2 × 팟이면 레이즈 대신 올인.
